# Expense Tracker

A simple console-based Expense Tracker developed using Java.

## Features

- Add expense
- View all expenses
- Search expenses by category
- Delete expense
- Calculate total expenses
- Find highest expense

## Technologies Used

- Java
- OOP
- ArrayList
- Scanner

## How to Run

1. Open the project in VS Code or IntelliJ IDEA.
2. Open the `src` folder.
3. Run `Main.java`.

- Classes and Objects
- Encapsulation
- ArrayList
- Methods
- Loops
- Conditional Statements
- Searching
